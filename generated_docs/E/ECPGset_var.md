# ECPGset_var

## Overview
Sets or updates a variable in the ECPG variable list, maintaining a mapping between variable numbers and their memory pointers for ECPG SQL operations.

## Definition
```c
void ECPGset_var(int number, void *pointer, int lineno)
```

## Detailed Description
This function manages the ECPG variable list (ivlist) by either updating an existing variable's pointer or adding a new variable entry. Variables in ECPG are identified by unique numbers and associated with memory pointers that hold their values. The function first searches the existing variable list to see if the variable number already exists - if found, it simply updates the pointer. If not found, it allocates a new var_list structure and adds it to the beginning of the linked list.

The function includes comprehensive error handling for memory allocation failures and integrates with the ECPG SQL Communication Area (SQLCA) for error reporting. When memory allocation fails, it sets appropriate error codes in the SQLCA structure and calls ECPGfree_auto_mem() to clean up any allocated memory.

## Parameters / Member Variables
- `number`: Unique identifier for the variable in the ECPG system
- `pointer`: Memory pointer to the variable's data storage location  
- `lineno`: Source line number for error reporting purposes

## Notes and Other Information
This function is part of the core ECPG variable management system and is typically called by code generated by the ECPG preprocessor. The ivlist is a global linked list that maintains all active variables. Memory allocation failures trigger comprehensive cleanup through ECPGfree_auto_mem() to prevent memory leaks. The function uses line numbers for precise error location reporting in embedded SQL applications.

## Simplified Source

```c
void ECPGset_var(int number, void *pointer, int lineno) {
    struct var_list *ptr;
    struct sqlca_t *sqlca = ECPGget_sqlca();

    // Check if SQLCA is available
    if (sqlca == NULL) {
        ecpg_raise(lineno, ECPG_OUT_OF_MEMORY, ECPG_SQLSTATE_ECPG_OUT_OF_MEMORY, NULL);
        return;
    }

    ecpg_init_sqlca(sqlca);

    // Search for existing variable in list
    for (ptr = ivlist; ptr != NULL; ptr = ptr->next) {
        if (ptr->number == number) {
            // Update existing variable pointer
            ptr->pointer = pointer;
            return;
        }
    }

    // Add new variable to list
    ptr = (struct var_list *) calloc(1L, sizeof(struct var_list));
    if (!ptr) {
        // Handle memory allocation failure
        sqlca = ECPGget_sqlca();
        if (sqlca != NULL) {
            sqlca->sqlcode = ECPG_OUT_OF_MEMORY;
            strncpy(sqlca->sqlstate, "YE001", sizeof(sqlca->sqlstate));
            snprintf(sqlca->sqlerrm.sqlerrmc, sizeof(sqlca->sqlerrm.sqlerrmc),
                    "out of memory on line %d", lineno);
            sqlca->sqlerrm.sqlerrml = strlen(sqlca->sqlerrm.sqlerrmc);
        }
        ECPGfree_auto_mem();
    } else {
        // Initialize and link new variable
        ptr->number = number;
        ptr->pointer = pointer;
        ptr->next = ivlist;
        ivlist = ptr;
    }
}
```
