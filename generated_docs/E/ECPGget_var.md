## Overview
Retrieves a variable pointer from the ECPG variable list by searching for the specified variable number.

## Definition
```c
void *ECPGget_var(int number)
```

## Detailed Description
This function provides a simple lookup mechanism for retrieving variable pointers from the ECPG variable list (ivlist). It performs a linear search through the linked list of variables, comparing the provided number against each variable's stored number until a match is found or the end of the list is reached. The function returns the associated pointer if the variable is found, or NULL if no matching variable exists.

This is a complementary function to ECPGset_var and is essential for the ECPG variable management system, allowing retrieval of previously registered variables during SQL statement execution.

## Parameters / Member Variables
- `number`: The unique identifier of the variable to retrieve

## Notes and Other Information
This function performs a simple O(n) linear search through the variable list. The function is thread-safe for read operations but should be used carefully in multi-threaded environments where concurrent modifications to ivlist might occur. It returns NULL for non-existent variables, requiring callers to handle this case appropriately. The function is typically called by code generated by the ECPG preprocessor rather than directly by user code.

## Simplified Source

```c
void *ECPGget_var(int number) {
    // Search through the variable list for matching number
    struct var_list *ptr;
    for (ptr = ivlist; ptr != NULL && ptr->number != number; ptr = ptr->next) {
        // Continue searching until found or end of list
    }

    // Return pointer if found, NULL otherwise
    return (ptr) ? ptr->pointer : NULL;
}
```
