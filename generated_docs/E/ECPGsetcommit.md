# ECPGsetcommit

## Location
src/interfaces/ecpg/ecpglib/connect.c: 158 - 194

## Overview
Controls the autocommit behavior of an ECPG database connection, allowing applications to switch between automatic and manual transaction commit modes.

## Definition
```c
bool ECPGsetcommit(int lineno, const char *mode, const char *connection_name)
```

## Detailed Description
This function manages the autocommit setting for ECPG database connections. When switching from autocommit on to off, it starts a new transaction if the connection is currently idle. When switching from off to on, it commits any active transaction before enabling autocommit. The function checks the current transaction status using libpq functions and executes appropriate BEGIN TRANSACTION or COMMIT commands as needed. It properly handles both named connections and the default connection, and provides comprehensive error checking and logging.

## Parameters / Member Variables
- `lineno`: Line number in the source file where this function is called (used for error reporting and logging)
- `mode`: String specifying the desired autocommit mode:
  - `"off"`: Disable autocommit (manual transaction control)
  - `"on"`: Enable autocommit (automatic transaction commits)
- `connection_name`: Name of the connection to modify, or NULL for the current/default connection

## Notes and Other Information
- Returns `true` on success, `false` on failure
- This is a public ECPG API function (no static qualifier)
- Uses `PQTRANS_IDLE` to determine if the connection is not currently in a transaction
- Performs actual SQL operations (BEGIN TRANSACTION, COMMIT) to change transaction state
- Updates the connection's `autocommit` field to reflect the new setting
- Uses ECPG_COMPAT_PGSQL compatibility mode for error checking
- Provides detailed logging of operations including line numbers for debugging
- Part of ECPG's transaction management infrastructure
- Essential for applications that need to control transaction boundaries explicitly
- Safe to call multiple times with the same mode (idempotent operation)
