## Overview
Creates and initializes a BitmapHeapScan plan node that reads heap tuples based on a bitmap of page locations generated by one or more BitmapIndexScan operations.

## Detailed Description
This function constructs a BitmapHeapScan plan node, which is the second stage of PostgreSQL's bitmap scan execution strategy. It takes a bitmap (generated by BitmapIndexScan nodes in its left subtree) that indicates which heap pages potentially contain qualifying tuples, then reads those pages from the heap table in an efficient manner. The bitmap approach allows PostgreSQL to read each relevant page only once, even when multiple index conditions point to tuples on the same page, significantly reducing I/O compared to nested loop approaches for moderately selective queries.

## Parameters / Member Variables
- `*qptlist`: Target list of expressions to be computed and returned by this scan
- `*qpqual`: Qualification conditions that need to be evaluated against heap tuples (may include non-index conditions)
- `*lefttree`: Child plan node that provides the bitmap (typically a BitmapIndexScan or BitmapOr/BitmapAnd node)
- `*bitmapqualorig`: Original (unprocessed) qualification conditions that generated the bitmap
- `scanrelid`: Range table index of the heap relation being scanned

## Notes and Other Information
- This is a static function within createplan.c for internal plan construction
- Always operates with a left child that provides the bitmap (BitmapIndexScan, BitmapOr, or BitmapAnd)
- The bitmap scan strategy is most effective for queries with moderate selectivity (not too few, not too many result tuples)
- Recheck conditions in qpqual handle cases where bitmap conditions may produce false positives
- The righttree is always NULL as bitmap heap scans only have one child providing the bitmap

## Simplified Source

```c
static BitmapHeapScan *make_bitmap_heapscan(List *qptlist, List *qpqual, Plan *lefttree,
                                             List *bitmapqualorig, Index scanrelid) {
    // Create new BitmapHeapScan node
    BitmapHeapScan *node = makeNode(BitmapHeapScan);
    Plan *plan = &node->scan.plan;

    // Set up basic plan fields
    plan->targetlist = qptlist;
    plan->qual = qpqual;
    plan->lefttree = lefttree;  // Child provides bitmap
    plan->righttree = NULL;     // No right child needed

    // Set BitmapHeapScan specific fields
    node->scan.scanrelid = scanrelid;
    node->bitmapqualorig = bitmapqualorig;

    return node;
}
```
