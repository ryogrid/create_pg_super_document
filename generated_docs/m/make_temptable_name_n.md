## Overview
make_temptable_name_n constructs a new temporary table name by appending an underscore and integer suffix to an existing temporary table name.

## Definition
static char *make_temptable_name_n(char *tempname, int n)

## Detailed Description
This utility function creates a new temporary table name by combining a base temporary table name with a numeric suffix. It uses PostgreSQL's StringInfo infrastructure to efficiently build the new name by appending an underscore followed by the specified integer to the input name. The function allocates memory for the result string, which must be managed by the caller. It's designed to work with PostgreSQL's temporary table naming conventions, particularly names of the form "pg_temp_NNN" generated by make_new_heap(), though it has limitations with double-quoted table names that contain special characters.

## Parameters / Member Variables
- `tempname`: Base temporary table name string to which the suffix will be appended
- `n`: Integer value to append as a suffix after an underscore

## Notes and Other Information
- Returns a palloc'd string that must be freed by the caller
- Uses StringInfo for efficient string building and memory management
- Currently works reliably with pg_temp_NNN style names but may have issues with complex quoted identifiers
- Part of the materialized view refresh infrastructure for creating uniquely named temporary tables
- The function comment notes potential future limitations with double-quoted table names containing special characters
- Designed for internal use in materialized view operations where multiple temporary tables may be needed with related but distinct names
