# emitShSecLabels

## Location
src/bin/pg_dump/dumputils.c: 693 - 726

## Overview
Constructs SECURITY LABEL commands using query results and appends them to a buffer for shared database objects.

## Definition
void emitShSecLabels(PGconn *conn, PGresult *res, PQExpBuffer buffer, const char *objtype, const char *objname)

## Detailed Description
This function processes the results of a security label query (typically generated by buildShSecLabelQuery) and constructs the corresponding SECURITY LABEL SQL commands. It iterates through all rows in the result set, extracting the provider and label values, and formats them into proper SECURITY LABEL FOR statements. The function handles proper quoting of identifiers and string literals, ensuring the generated SQL is syntactically correct and safe from injection attacks.

## Parameters / Member Variables
- `conn`: PostgreSQL database connection used for proper string literal escaping
- `res`: PGresult containing the query results with provider and label columns
- `buffer`: PQExpBuffer to which the SECURITY LABEL commands will be appended
- `objtype`: Type name of the target object (e.g., "DATABASE", "TABLESPACE")
- `objname`: Name of the target object (not pre-quoted)
