## Overview
Converts text from EUC-KR (Extended Unix Code for Korean) encoding to UTF-8 encoding using PostgreSQL's encoding conversion infrastructure.

## Definition
```c
Datum euc_kr_to_utf8(PG_FUNCTION_ARGS)
```

## Detailed Description
This function is a PostgreSQL conversion procedure that performs character encoding conversion from EUC-KR to UTF-8. It follows the standard PostgreSQL conversion function interface, accepting source and destination buffers along with conversion parameters. The function uses the `LocalToUtf` utility function with a precomputed radix tree (`euc_kr_to_unicode_tree`) for efficient character mapping. The conversion tree is generated from mapping tables that define the correspondence between EUC-KR character codes and Unicode code points.

The function validates the encoding parameters using `CHECK_ENCODING_CONVERSION_ARGS` to ensure the source encoding is PG_EUC_KR and the destination is PG_UTF8. It then delegates the actual conversion work to the `LocalToUtf` function, which handles the byte-by-byte conversion using the mapping tree.

## Parameters / Member Variables

- `src` (argument 2): Source string buffer containing EUC-KR encoded text
- `dest` (argument 3): Destination buffer for UTF-8 encoded output  
- `len` (argument 4): Length of the source string in bytes
- `noError` (argument 5): Boolean flag indicating whether to suppress conversion errors
