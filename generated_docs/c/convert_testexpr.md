# convert_testexpr

## Overview
Converts a testexpr from the parser into executable form by replacing PARAM_SUBLINK Params with actual Params or Vars representing sub-select results.

## Definition
```c
static Node *convert_testexpr(PlannerInfo *root, Node *testexpr, List *subst_nodes)
```

## Detailed Description
The `convert_testexpr` function serves as the main entry point for transforming test expressions during query planning. It takes a test expression that contains placeholder parameters (PARAM_SUBLINK) and converts them into concrete parameters or variables that reference the actual results from sub-queries. This transformation is essential for making sub-select expressions executable within the broader query plan.

The function operates by setting up a conversion context and delegating the actual work to `convert_testexpr_mutator`, which performs a tree walk to find and replace the appropriate nodes. This is part of PostgreSQL's subquery processing pipeline where subqueries are converted from their parsed form into executable plans.

## Parameters / Member Variables
- `root`: PlannerInfo structure containing planning context and state information
- `testexpr`: The test expression node tree that needs to be converted  
- `subst_nodes`: List of nodes to substitute for the PARAM_SUBLINK parameters, typically generated by `generate_subquery_params` or `generate_subquery_vars`
