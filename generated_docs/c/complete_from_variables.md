# complete_from_variables

## Location
[src/bin/psql/tab-complete.c:5753-5797](https://github.com/postgres/postgres/tree/92268b35d04c2de416279f187d12f264afa22614/src/bin/psql/tab-complete.c#L5753-L5797)

## Overview
Provides tab completion for PostgreSQL's psql variable names, with options for prefix/suffix formatting and filtering based on whether variables have values.

## Definition
```c
static char **complete_from_variables(const char *text, const char *prefix, const char *suffix, bool need_value)
```

## Detailed Description
This function generates a list of psql variable names for tab completion by iterating through all variables in the current psql session. It supports flexible formatting through prefix and suffix parameters, and can optionally filter variables based on whether they currently have values. The function builds a dynamic array of formatted variable names, processes them through the completion system, and properly manages memory cleanup.

## Parameters / Member Variables
- `text`: The input text to match against (passed to completion system)
- `prefix`: String to prepend to each variable name (e.g., for quoting)
- `suffix`: String to append to each variable name (e.g., closing quotes)
- `need_value`: If true, only include variables that currently have values; if false, include all variables including unset special variables with hooks

## Notes and Other Information
- Iterates through the linked list of psql variables starting from pset.vars->next
- Dynamically grows the variable names array as needed through append_variable_names
- Properly NULL-terminates the variable names array before passing to completion system
- Includes comprehensive memory cleanup for both the array and individual strings
- The need_value parameter allows filtering: when true, only variables with current values are included; when false, special variables with hooks are included even if unset
- Returns the matches array generated by the completion system
- Used extensively throughout the tab completion system for various psql commands that work with variables
