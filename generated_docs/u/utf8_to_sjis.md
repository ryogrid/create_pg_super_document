## Detailed Description
This function serves as a PostgreSQL conversion procedure that transforms text from UTF-8 encoding to Shift-JIS (Japanese Industrial Standards) encoding. It is the reverse counterpart to sjis_to_utf8 and is part of PostgreSQL's comprehensive multibyte character set support. The function uses a radix tree-based lookup mechanism (sjis_from_unicode_tree) to efficiently map Unicode characters to their Shift-JIS equivalents.

The conversion process validates encoding arguments, performs the character conversion using the UtfToLocal utility function, and returns the number of bytes successfully converted. Like its counterpart, the function supports configurable error handling where conversion failures can either raise exceptions or be silently ignored based on the noError parameter.

Datum
utf8_to_sjis(PG_FUNCTION_ARGS)
{
    // Extract function arguments
    unsigned char *src = (unsigned char *) PG_GETARG_CSTRING(2);
    unsigned char *dest = (unsigned char *) PG_GETARG_CSTRING(3);
    int len = PG_GETARG_INT32(4);
    bool noError = PG_GETARG_BOOL(5);

    // Validate encoding conversion arguments
    CHECK_ENCODING_CONVERSION_ARGS(PG_UTF8, PG_SJIS);

    // Convert using radix tree mapping
    int converted = UtfToLocal(src, len, dest,
                              &sjis_from_unicode_tree,
                              NULL, 0, NULL,
                              PG_SJIS, noError);

    PG_RETURN_INT32(converted);
}
