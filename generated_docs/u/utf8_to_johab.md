## Detailed Description
This function is a PostgreSQL conversion procedure that implements character encoding conversion from UTF-8 to JOHAB (Korean standard). It serves as the reverse conversion counterpart to `johab_to_utf8`, enabling bidirectional encoding conversion between UTF-8 and JOHAB formats. JOHAB is a Korean character encoding standard that was developed for use in South Korea and is particularly suited for representing Hangul characters.

The function uses PostgreSQL's radix tree-based conversion mechanism with a different mapping tree (`johab_from_unicode_tree`) to efficiently convert UTF-8 encoded Unicode characters to their corresponding JOHAB representations. Like its counterpart, it follows PostgreSQL's standard conversion function interface.

## Notes and Other Information
- The conversion uses a radix tree data structure (`johab_from_unicode_tree`) defined in `utf8_to_johab.map` for efficient character mapping
- The map file is auto-generated by `UCS_to_JOHAB.pl` script, ensuring consistency with the reverse conversion
- Uses `UtfToLocal` instead of `LocalToUtf` as it converts from UTF-8 (Unicode) to a local encoding (JOHAB)
- The function validates encoding parameters ensuring UTF-8 source and JOHAB destination
- Returns the number of bytes successfully converted, enabling partial conversion tracking
- Supports graceful error handling through the noError parameter for invalid UTF-8 sequences
- Essential for Korean text processing in PostgreSQL databases that need to interface with JOHAB-based systems

Datum
utf8_to_johab(PG_FUNCTION_ARGS)
{
    // Extract function arguments
    unsigned char *src = (unsigned char *) PG_GETARG_CSTRING(2);
    unsigned char *dest = (unsigned char *) PG_GETARG_CSTRING(3);
    int len = PG_GETARG_INT32(4);
    bool noError = PG_GETARG_BOOL(5);

    // Validate encoding conversion arguments
    CHECK_ENCODING_CONVERSION_ARGS(PG_UTF8, PG_JOHAB);

    // Convert using radix tree mapping
    int converted = UtfToLocal(src, len, dest,
                              &johab_from_unicode_tree,
                              NULL, 0, NULL,
                              PG_JOHAB, noError);

    PG_RETURN_INT32(converted);
}
