## Overview
Converts text from UTF-8 encoding to EUC-KR (Extended Unix Code for Korean) encoding using PostgreSQL's encoding conversion infrastructure.

## Definition

## Detailed Description
This function is a PostgreSQL conversion procedure that performs character encoding conversion from UTF-8 to EUC-KR. It serves as the reverse counterpart to `euc_kr_to_utf8`, following the same standard PostgreSQL conversion function interface. The function uses the `UtfToLocal` utility function with a precomputed radix tree (`euc_kr_from_unicode_tree`) for efficient character mapping from Unicode code points back to EUC-KR character codes.

The conversion process validates the encoding parameters to ensure the source is UTF-8 and destination is EUC-KR, then delegates to `UtfToLocal` for the actual byte-level conversion. The mapping tree used here is the inverse of the one used in `euc_kr_to_utf8`, enabling bidirectional conversion between the two encodings.

- The radix tree enables efficient lookup from Unicode code points to EUC-KR codes
