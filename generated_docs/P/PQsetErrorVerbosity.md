# PQsetErrorVerbosity

## Location
src/interfaces/libpq/fe-connect.c: 7297 - 7308

## Overview
Sets the verbosity level for error messages generated by libpq, controlling how much detail is included in error reports.

## Definition


## Detailed Description
PQsetErrorVerbosity allows applications to control the amount of detail included in error messages from the PostgreSQL client library. The function updates the connection's verbosity setting and returns the previous verbosity level, allowing applications to temporarily change the verbosity and restore it later. This setting affects how error messages are formatted and how much information is provided when database operations fail.

## Parameters / Member Variables
- : The database connection handle (if NULL, returns PQERRORS_DEFAULT)
- : The desired verbosity level from the PGVerbosity enum:
  - : Single-line error messages
  - : Recommended style with moderate detail
  - : All available error details
  - : Only error severity and SQLSTATE code

## Notes and Other Information
- Returns the previous verbosity setting, allowing for restoration
- If connection is NULL, returns PQERRORS_DEFAULT as a safe fallback
- This setting affects all subsequent error messages from the connection
- Commonly used by command-line tools to adjust error reporting based on user preferences
- The verbosity setting is stored in the connection structure and persists until changed
