# PQerrorMessage

## Location
src/interfaces/libpq/fe-connect.c: 7159 - 7184

## Overview
Returns the most recent error message generated by operations on the specified PostgreSQL connection, providing detailed error information for debugging and error handling.

## Definition


## Detailed Description
This function retrieves the error message string associated with a PostgreSQL connection. It returns a pointer to a null-terminated string containing the most recent error message generated by libpq operations on this connection. The function handles several error conditions gracefully:

1. If the connection pointer is NULL, it returns a localized "connection pointer is NULL" message
2. If the internal error message buffer is broken (typically due to memory allocation failures), it returns a localized "out of memory" message  
3. Otherwise, it returns the actual error message stored in the connection's error buffer

The error messages are persistent until the next operation that might generate a new error, making this function reliable for error reporting after failed operations.

## Parameters / Member Variables
- : A pointer to the PGconn structure representing the database connection. Can be NULL, which will result in an appropriate error message.

## Notes and Other Information
- Returns a pointer to internal libpq memory - the string should not be freed by the caller
- The returned string may be modified by subsequent libpq operations, so copy it if persistence is needed
- Error messages are localized using libpq_gettext for internationalization support
- This is one of the most frequently used libpq functions for error handling and debugging
- The function is safe to call even with invalid connection pointers
- Error messages typically include context about what operation failed and why
