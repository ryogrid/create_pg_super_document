# postprocess_setop_tlist

## Location
src/backend/optimizer/plan/planner.c: 5747 - 5783

## Overview
Post-processes the target list returned by plan_set_operations() by transposing sort key information from the original target list to the new target list.

## Definition
```c
static List *postprocess_setop_tlist(List *new_tlist, List *orig_tlist)
```

## Detailed Description
This static function is responsible for fixing up the target list that results from set operations (UNION, INTERSECT, EXCEPT). It takes the new target list generated by the set operation planning and the original target list, then transfers essential sort key information (ressortgroupref) from the original entries to the corresponding new entries.

The function enforces that resjunk (result junk) columns are not supported in set operation results, issuing errors if any are encountered. This is a current limitation of PostgreSQL's set operation implementation where resjunk sort keys would require projecting an entirely new target list.

## Parameters / Member Variables
- `new_tlist`: The target list returned by plan_set_operations() that needs to be fixed up
- `orig_tlist`: The original target list containing sort key information to be transferred
