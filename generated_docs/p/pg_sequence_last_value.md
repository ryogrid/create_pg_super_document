## Overview
A SQL-callable function that returns the last generated value from a sequence, with special handling for temporary sequences and standby servers.

## Detailed Description
The  function retrieves the most recent value generated by a sequence, but only if the sequence has actually been called (i.e.,  is true). This function differs significantly from  in that it operates on a specific sequence rather than the session's most recently used sequence.

Key behavioral characteristics:
- **Permission enforcement**: Requires SELECT or USAGE privileges on the sequence
- **Temporary sequence handling**: Returns NULL for other sessions' temporary sequences rather than erroring
- **Standby server compatibility**: Returns NULL for unlogged sequences on standby servers to avoid errors
- **Called state checking**: Returns NULL if the sequence has never been called (is_called = false)
- **Thread safety**: Properly locks the sequence during access

The function opens and locks the target sequence, reads its current state from the sequence data tuple, and returns the last_value if the sequence has been called. This provides a safe way to inspect sequence state without advancing the sequence.

## Parameters / Member Variables
- Function takes a single OID argument representing the sequence relation ID (accessed via PG_GETARG_OID(0))
- Returns either the last generated value as Int64 or NULL
