# find_derived_clause_for_ec_member

## Location

## Overview
Searches for a previously-derived restrictive clause that mentions a specific equivalence class member and equates it to a constant value.

## Definition
```c
RestrictInfo *find_derived_clause_for_ec_member(EquivalenceClass *ec,
                                               EquivalenceMember *em)
```

## Detailed Description
This function searches through the derived clauses of an equivalence class to find one that references a specific equivalence member. It is designed to work with equivalence classes that contain constants (ec_has_const = true), where the function looks for derived clauses that equate non-constant members to constant values.

The function assumes that the equivalence class contains at least one constant member, and the provided equivalence member is non-constant. Due to the way derived clauses are generated by generate_base_implied_equalities_const, there should be exactly one derived clause mentioning the given equivalence member, and that clause should equate the member to a constant.

The search relies on the fact that non-constant members are placed on the left side of derived clauses by the clause generation process, so it only needs to check the left_em field of each RestrictInfo in the equivalence class's ec_derives list.

## Parameters / Member Variables
- `ec`: EquivalenceClass that should contain constants (ec_has_const must be true)
- `em`: EquivalenceMember that should be non-constant (em_is_const must be false)
