# GetScanKeyword

## Location

## Overview
GetScanKeyword is an inline utility function that retrieves the text representation of a keyword by its index from a ScanKeywordList structure.

## Definition


## Detailed Description
GetScanKeyword provides a simple and efficient way to access keyword strings from a ScanKeywordList structure. It uses pointer arithmetic to calculate the memory location of the nth keyword by adding the offset stored in the kw_offsets array to the base address of the kw_string buffer. This design allows for compact storage of keywords as a single concatenated string with null terminators, while maintaining O(1) access time to individual keywords.

The function is implemented as a static inline function for optimal performance, as it's frequently used during keyword lookup operations in PostgreSQL's lexical analysis phase.

## Parameters / Member Variables
- : The zero-based index of the keyword to retrieve
- : Pointer to a ScanKeywordList structure containing the keyword data

## Notes and Other Information
- The function assumes that the index  is valid (0 <= n < keywords->num_keywords)
- No bounds checking is performed for performance reasons
- The returned pointer points directly into the kw_string buffer and should not be modified
- This function is typically used in conjunction with ScanKeywordLookup for efficient keyword recognition in PostgreSQL's scanner
- The keyword data is usually generated by src/tools/gen_keywordlist.pl from PG_KEYWORD macros
