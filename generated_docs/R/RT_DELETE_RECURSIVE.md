## Overview
RT_DELETE_RECURSIVE is a macro that generates the name for the recursive deletion function used internally by the radix tree implementation to delete keys from the tree structure.

## Definition
```c
#define RT_DELETE_RECURSIVE RT_MAKE_NAME(delete_recursive)
```

## Detailed Description
RT_DELETE_RECURSIVE is a macro-generated function name that serves as the workhorse for the RT_DELETE operation in PostgreSQL's radix tree implementation. The actual function signature, when expanded, is:

```c
static bool RT_DELETE_RECURSIVE(RT_RADIX_TREE *tree, RT_PTR_ALLOC *parent_slot, uint64 key, int shift)
```

This function recursively traverses the radix tree from the root towards the leaves to locate and delete a specified key. It handles the tree structure maintenance during deletion, including node consolidation and memory cleanup. The function uses a shift-based approach to process the key chunk by chunk, descending through the tree levels until it reaches the target leaf or determines the key doesn't exist.

## Parameters / Member Variables
- `tree`: Pointer to the radix tree structure being modified
- `parent_slot`: Pointer to the parent node's slot that references the current node
- `key`: The 64-bit key value to be deleted from the tree
- `shift`: The current bit shift level used to extract the appropriate key chunk for the current tree level
