# DefineOperator

## Location
src/backend/commands/operatorcmds.c: 67 - 274

## Overview
DefineOperator is the main entry point for creating new SQL operators in PostgreSQL, processing the CREATE OPERATOR command by parsing parameters and delegating the actual creation to OperatorCreate().

## Definition
```c
ObjectAddress DefineOperator(List *names, List *parameters)
```

## Detailed Description
DefineOperator extracts and validates all information from the parameter list generated by the parser for a CREATE OPERATOR SQL command. It handles namespace resolution, permission checking, parameter parsing, type validation, function lookup, and optional estimator validation before calling OperatorCreate() to perform the actual operator creation.

The function processes various operator attributes including:
- Left and right argument types (leftarg, rightarg)
- Implementation function (function/procedure)
- Optional commutator and negator operators
- Optional selectivity estimation functions (restrict, join)
- Hash and merge join capability flags
- Legacy sort comparison operators (converted to merge capability)

## Parameters / Member Variables
- `names`: List of qualified names specifying the operator name and optional schema
- `parameters`: List of DefElem structures containing operator definition attributes

## Notes and Other Information
- Requires CREATE permission on the target namespace
- Requires USAGE permission on argument and return types
- Requires EXECUTE permission on the implementation function
- Postfix operators are explicitly not supported (right argument is mandatory)
- Legacy sort operator attributes (sort1, sort2, ltcmp, gtcmp) are converted to canMerge=true
- Unknown operator attributes generate warnings rather than errors for backward compatibility
- Both "function" and "procedure" keywords are accepted for specifying the implementation function
