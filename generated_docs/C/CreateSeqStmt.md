## Overview
CreateSeqStmt represents a CREATE SEQUENCE statement in PostgreSQL's parse tree, used to define a new sequence object in the database.

## Definition

```c
typedef struct CreateSeqStmt
{
	NodeTag		type;
	RangeVar   *sequence;		/* the sequence to create */
	List	   *options;
	Oid			ownerId;		/* ID of owner, or InvalidOid for default */
	bool		for_identity;
	bool		if_not_exists;	/* just do nothing if it already exists? */
} CreateSeqStmt;
```
## Detailed Description
CreateSeqStmt is a parse tree node structure that encapsulates all information needed to create a sequence in PostgreSQL. It is generated by the parser when processing CREATE SEQUENCE SQL statements and is used throughout the system to represent sequence creation operations. The structure supports various sequence options, ownership specification, identity column integration, and conditional creation with IF NOT EXISTS clause.

## Parameters / Member Variables
- : NodeTag identifier for this parse node type
- : RangeVar pointer specifying the name and schema of the sequence to create
- : List of DefElem nodes containing sequence options (START, INCREMENT, MINVALUE, MAXVALUE, CACHE, CYCLE, etc.)
- : Object ID of the sequence owner, or InvalidOid to use default ownership
- : Boolean flag indicating if this sequence is being created for an identity column
- : Boolean flag for conditional creation - if true, no error is raised if sequence already exists
