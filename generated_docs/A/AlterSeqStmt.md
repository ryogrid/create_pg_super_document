## Overview
AlterSeqStmt represents an ALTER SEQUENCE statement in PostgreSQL parse tree, used to modify properties of an existing sequence object.

## Definition
```c
typedef struct AlterSeqStmt
{
    NodeTag     type;
    RangeVar   *sequence;        /* the sequence to alter */
    List       *options;
    bool        for_identity;
    bool        missing_ok;      /* skip error if a role is missing? */
} AlterSeqStmt;
```

## Detailed Description
AlterSeqStmt is a parse tree node structure that encapsulates information needed to alter an existing sequence in PostgreSQL. It is generated by the parser when processing ALTER SEQUENCE SQL statements and is used to modify sequence parameters such as increment value, start value, minimum/maximum values, cache size, and cycling behavior. The structure supports both regular sequences and identity column sequences.

## Parameters / Member Variables
- `type`: NodeTag identifier for this parse node type
- `sequence`: RangeVar pointer specifying the name and schema of the sequence to alter  
- `options`: List of DefElem nodes containing sequence options to modify (START, INCREMENT, MINVALUE, MAXVALUE, CACHE, CYCLE, RESTART, etc.)
- `for_identity`: Boolean flag indicating if this sequence alteration is for an identity column
- `missing_ok`: Boolean flag to skip errors if the sequence does not exist (used with IF EXISTS clause)
