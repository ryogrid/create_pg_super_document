# AtProcExit_Twophase

## Location
src/backend/access/transam/twophase.c: 294 - 303

## Overview
An exit hook function that ensures proper cleanup of two-phase commit resources when a process terminates.

## Definition
static void AtProcExit_Twophase(int code, Datum arg)

## Detailed Description
This function serves as a process exit callback specifically designed to handle cleanup of two-phase commit resources when a PostgreSQL backend process terminates. It acts as a safety mechanism to ensure that any global transaction entries that were locked or being worked on by the terminating process are properly released.

The function implements a simple but effective cleanup strategy by delegating to AtAbort_Twophase(), which handles the actual resource cleanup logic. This approach ensures consistency between abort scenarios and process termination scenarios, as both require the same type of cleanup operations.

As a static function, it's only used internally within the twophase.c module and is registered as an exit callback when certain two-phase commit operations begin.
