# ATExecAddIdentity

## Location
[src/backend/commands/tablecmds.c:8023-8128](https://github.com/postgres/postgres/tree/92268b35d04c2de416279f187d12f264afa22614/src/backend/commands/tablecmds.c#L8023-L8128)

## Overview
ATExecAddIdentity implements the ALTER TABLE ALTER COLUMN ADD IDENTITY command, adding identity column properties to an existing column in a PostgreSQL relation.

## Definition
```c
static ObjectAddress ATExecAddIdentity(Relation rel, const char *colName, Node *def, LOCKMODE lockmode, bool recurse, bool recursing)
```

## Detailed Description
This function transforms an existing column into an identity column by updating the column's attributes in the PostgreSQL system catalogs. Identity columns automatically generate unique values using sequences, similar to AUTO_INCREMENT in other database systems.

The function performs extensive validation before making changes:
- Ensures the column exists and is not a system column
- Verifies the column is already NOT NULL (required for identity columns)
- Checks that the column is not already an identity column
- Confirms the column doesn't already have a default value
- Validates partitioning constraints (identity cannot be added to only the partitioned table without RECURSE, and cannot be added directly to partitions)

For partitioned tables, the function recursively applies the identity property to all child partitions when the recurse flag is set. The identity property is not inherited through regular table inheritance, only through partitioning.

## Parameters / Member Variables
- `rel`: The relation containing the column to modify
- `colName`: Name of the column to convert to an identity column
- `def`: ColumnDef node containing identity specifications (GENERATED ALWAYS/BY DEFAULT)
- `lockmode`: Lock mode to use when accessing child relations
- `recurse`: Whether to apply changes to partitioned table children
- `recursing`: Internal flag indicating this is a recursive call to a partition

- This is a static function within tablecmds.c, part of the ALTER TABLE infrastructure
- Identity columns implicitly require NOT NULL constraint
- Identity property is not inherited through regular table inheritance, only through partitioning
- The function uses recursive calls to propagate identity properties to all partitions
- Generates appropriate error messages for various invalid states (column doesn't exist, already identity, has default, etc.)
- Updates the pg_attribute catalog to set the attidentity field
- Supports both GENERATED ALWAYS and GENERATED BY DEFAULT identity types via the ColumnDef structure

```c
static ObjectAddress ATExecAddIdentity(Relation rel, const char *colName, Node *def,
                                      LOCKMODE lockmode, bool recurse, bool recursing) {
    Relation attrelation;
    HeapTuple tuple;
    Form_pg_attribute attTup;
    AttrNumber attnum;
    ObjectAddress address;
    ColumnDef *cdef = castNode(ColumnDef, def);
    bool ispartitioned = (rel->rd_rel->relkind == RELKIND_PARTITIONED_TABLE);

    // Validate partitioning rules
    if (ispartitioned && !recurse) {
        ereport(ERROR, "cannot add identity to a column of only the partitioned table");
    }
    if (rel->rd_rel->relispartition && !recursing) {
        ereport(ERROR, "cannot add identity to a column of a partition");
    }

    // Open attribute catalog
    attrelation = table_open(AttributeRelationId, RowExclusiveLock);

    // Find the specified column
    tuple = SearchSysCacheCopyAttName(RelationGetRelid(rel), colName);
    if (!HeapTupleIsValid(tuple)) {
        ereport(ERROR, "column \"%s\" of relation \"%s\" does not exist",
               colName, RelationGetRelationName(rel));
    }

    attTup = (Form_pg_attribute) GETSTRUCT(tuple);
    attnum = attTup->attnum;

    // Validate column constraints
    if (attnum <= 0) {
        ereport(ERROR, "cannot alter system column \"%s\"", colName);
    }

    if (!attTup->attnotnull) {
        ereport(ERROR, "column \"%s\" must be declared NOT NULL before identity can be added",
               colName);
    }

    if (attTup->attidentity) {
        ereport(ERROR, "column \"%s\" is already an identity column", colName);
    }

    if (attTup->atthasdef) {
        ereport(ERROR, "column \"%s\" already has a default value", colName);
    }

    // Update the column to be an identity column
    attTup->attidentity = cdef->identity;
    CatalogTupleUpdate(attrelation, &tuple->t_self, tuple);

    // Trigger post-alter hook
    InvokeObjectPostAlterHook(RelationRelationId, RelationGetRelid(rel), attTup->attnum);

    // Prepare return address
    ObjectAddressSubSet(address, RelationRelationId, RelationGetRelid(rel), attnum);

    // Cleanup
    heap_freetuple(tuple);
    table_close(attrelation, RowExclusiveLock);

    // Recurse to partitions if needed
    if (recurse && ispartitioned) {
        List *children = find_inheritance_children(RelationGetRelid(rel), lockmode);

        foreach(lc, children) {
            Relation childrel = table_open(lfirst_oid(lc), NoLock);
            ATExecAddIdentity(childrel, colName, def, lockmode, recurse, true);
            table_close(childrel, NoLock);
        }
    }

    return address;
}
```
