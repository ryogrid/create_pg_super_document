## Overview
Searches for a basic word form in the prefix tree dictionary to validate whether a word generated by affix rules exists and has the appropriate affix flag association.

## Definition


## Detailed Description
FindWord performs a binary search through the dictionary's prefix tree to locate a specific word and validate its affix associations. The function is designed to handle compound word validation and affix rule verification. It traverses the prefix tree character by character, using binary search at each node to efficiently locate the path corresponding to the input word.

The function implements several validation checks:
1. Verifies that compound-only words are accessed with appropriate compound flags
2. Validates that the provided affix flag is actually associated with the found word
3. Handles compound word flag matching using bitwise operations

The search process uses a binary search algorithm at each tree node to quickly locate the correct character branch, making it efficient even for large dictionaries.

- : The basic form of the word to search for in the dictionary

- Uses binary search for efficient traversal of the prefix tree structure
- Handles compound word restrictions through FF_COMPOUNDONLY flag checking
- The flag parameter is masked with FF_COMPOUNDFLAGMASK before processing
- Static function, only accessible within the spell.c module
- Implements character-by-character tree traversal with uint8 pointer arithmetic
- Affix rule validation ensures that applied transformations are legitimate for the base word
