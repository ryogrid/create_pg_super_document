## Overview
A static internal function that converts string representations of PostgreSQL Node trees back into actual Node data structures, with support for optionally restoring location fields during parsing.

## Definition


## Detailed Description
This function serves as the core implementation for PostgreSQL's string-to-node deserialization mechanism. It takes a string representation of a Node tree (typically generated by nodeToString) and reconstructs the corresponding in-memory Node data structure. The function is designed to be re-entrant safe by carefully saving and restoring the global pg_strtok parser state.

The function supports conditional restoration of location fields through the restore_loc_fields parameter, which is primarily used for debugging purposes when the WRITE_READ_PARSE_PLAN_TREES flag is enabled. This allows the parser to either restore original source location information or set location fields to -1 (indicating no location information).

The parsing process relies on the nodeRead function from readfuncs.c, which handles the actual token-by-token parsing of the string representation.

## Parameters / Member Variables
- : The string representation of the Node tree to be parsed
- : Boolean flag indicating whether to restore location fields (true) or set them to -1 (false)
