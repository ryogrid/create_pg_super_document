## Detailed Description
ScanKeywordLookup performs case-insensitive keyword matching against a predefined list of SQL keywords. The function uses a perfect hash function to efficiently locate potential matches and then performs character-by-character comparison to verify the match. The implementation deliberately uses ASCII-only case conversion (only translating 'A'-'Z' to 'a'-'z') to comply with SQL99 specification requirements, avoiding locale-specific case conversions that could produce incorrect results in some locales (such as Turkish).

The function operates in several phases:
1. **Length check**: Immediately rejects strings longer than the maximum keyword length to avoid unnecessary processing
2. **Hash computation**: Uses the perfect hash function to identify a candidate keyword
3. **Range validation**: Ensures the hash result is within valid bounds
4. **Character-by-character comparison**: Performs ASCII-only case-insensitive comparison between input and candidate keyword

The lookup mechanism is optimized for performance with early rejection strategies and assumes the hash function produces case-insensitive results for the keyword set.

// Simplified version of ScanKeywordLookup
int ScanKeywordLookup(const char *str, const ScanKeywordList *keywords) {
    // Step 1: Quick length check to avoid processing overly long strings
    size_t len = strlen(str);
    if (len > keywords->max_kw_len)
        return -1;

    // Step 2: Compute perfect hash for the input string
    int hash_result = keywords->hash(str, len);

    // Step 3: Validate hash is within keyword table bounds
    if (hash_result < 0 || hash_result >= keywords->num_keywords)
        return -1;

    // Step 4: Get candidate keyword and perform case-insensitive comparison
    const char *candidate_keyword = GetScanKeyword(hash_result, keywords);

    // Character-by-character comparison with ASCII-only case conversion
    while (*str != '\0') {
        char input_char = *str++;

        // Convert uppercase ASCII to lowercase (A-Z -> a-z only)
        if (input_char >= 'A' && input_char <= 'Z')
            input_char += 'a' - 'A';

        if (input_char != *candidate_keyword++)
            return -1;
    }

    // Ensure candidate keyword is fully consumed
    if (*candidate_keyword != '\0')
        return -1;

    // Success: return the keyword index
    return hash_result;
}
