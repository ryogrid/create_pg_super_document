## Overview
ScanCKeywordLookup is a case-sensitive keyword lookup function used in PostgreSQL's ECPG (Embedded C in PostgreSQL) preprocessor to identify C language keywords during lexical analysis.

## Definition
```c
int ScanCKeywordLookup(const char *text)
```

## Detailed Description
This function performs a case-sensitive keyword lookup for C language keywords using a perfect hash table. It is specifically designed for the ECPG preprocessor, which needs to recognize both SQL and C keywords during parsing of embedded SQL code in C programs. The function uses a perfect hash algorithm to efficiently determine if a given text string matches a known C keyword and returns the corresponding token value.

The function implements an optimized lookup strategy:
1. First performs a quick length check against the maximum keyword length to avoid unnecessary hashing
2. Computes a perfect hash value for the input text
3. Validates the hash is within the valid range
4. Retrieves the keyword at the hash position and performs exact string comparison
5. Returns the token value if matched, or -1 if no match found

Unlike the general ScanKeywordLookup function, this variant uses case-sensitive matching with strcmp() rather than case-insensitive comparison, which is appropriate for C language keywords that are case-sensitive.

## Parameters / Member Variables
- `text`: A null-terminated C string containing the potential keyword to look up. The function performs case-sensitive matching against known C keywords.
