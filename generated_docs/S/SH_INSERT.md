## Detailed Description
SH_INSERT is part of PostgreSQL's simple hash table infrastructure that provides a high-level interface for inserting elements. This macro generates a function name that follows the naming convention for hash table operations. The generated function serves as a convenient wrapper around the internal insertion mechanism.

The function performs these operations:
1. Computes the hash value for the provided key using SH_HASH_KEY
2. Delegates the actual insertion to SH_INSERT_HASH_INTERNAL with the computed hash
3. Returns a pointer to the hash table element (either existing or newly inserted)
4. Sets the found parameter to indicate whether the key already existed

This is the standard entry point for hash table insertion when you have a key but haven't pre-computed its hash value. It abstracts away the hash computation details from the caller.

## Notes and Other Information
- This is the most commonly used insertion function for hash tables since it handles hash computation automatically
- The function is a thin wrapper that computes the hash and delegates to SH_INSERT_HASH_INTERNAL
- If you already have a pre-computed hash value, use SH_INSERT_HASH instead for better performance
- The function follows the PostgreSQL convention of returning a pointer to the element rather than a boolean success indicator
- The found parameter allows callers to distinguish between insertions of new keys and lookups of existing keys
- The function scope (SH_SCOPE) can be configured to control visibility (static, extern, etc.)
