## Overview
ScanKeywordList is a data structure that encapsulates all information needed for efficient keyword lookup operations in PostgreSQL's lexical analysis system.

## Definition

```c
typedef struct ScanKeywordList
{
	const char *kw_string;		/* all keywords in order, separated by \0 */
	const uint16 *kw_offsets;	/* offsets to the start of each keyword */
	ScanKeywordHashFunc hash;	/* perfect hash function for keywords */
	int			num_keywords;	/* number of keywords */
	int			max_kw_len;		/* length of longest keyword */
} ScanKeywordList;
```
## Detailed Description
ScanKeywordList provides a compact and efficient representation of keyword sets for PostgreSQL's scanner. The structure employs several optimization strategies:

1. **Space-efficient storage**: All keywords are stored as a single concatenated string (kw_string) with null terminators, reducing memory fragmentation and improving cache locality.

2. **Fast random access**: The kw_offsets array provides O(1) access to individual keywords by storing byte offsets into the kw_string.

3. **Optimized lookup**: A perfect hash function enables very fast keyword recognition without hash collisions.

4. **Metadata for bounds checking**: num_keywords and max_kw_len provide essential information for validation and optimization.

The contents of this structure are typically auto-generated by src/tools/gen_keywordlist.pl from header files containing PG_KEYWORD macros, ensuring consistency and reducing manual maintenance.
