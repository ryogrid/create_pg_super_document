## Detailed Description
SH_RESET is part of PostgreSQL's simple hash table infrastructure defined in simplehash.h. This macro generates a function name that follows the naming convention for hash table operations. When used with a specific prefix (defined by SH_PREFIX), it creates a reset function that clears all entries from a hash table while keeping the table structure intact.

The generated reset function performs these operations:
1. Zeros out all hash table data using memset()
2. Resets the member count to 0
3. Preserves the table's allocated size and structure

This is more efficient than destroying and recreating a hash table when you need to clear all entries but plan to reuse the table.

## Simplified Source

```c
SH_SCOPE void
SH_RESET(SH_TYPE *tb)
{
    // Clear all hash table data to zero
    memset(tb->data, 0, sizeof(SH_ELEMENT_TYPE) * tb->size);

    // Reset member count to zero
    tb->members = 0;
}
```

**What it does:** This function clears all entries from a hash table without deallocating memory. It zeros out the entire data array using memset and resets the member count to zero, effectively giving you an empty hash table that retains its allocated size and can be immediately reused.
