# rbt_populate

## Location
src/test/modules/test_rbtree/test_rbtree.c: 127 - 163

## Overview
Populates an empty red-black tree with a specified number of integers in arithmetic progression, inserting them in random order to test tree operations and collision handling.

## Definition
```c
static void rbt_populate(RBTree *tree, int size, int step)
```

## Detailed Description
rbt_populate fills an empty red-black tree with integers forming an arithmetic sequence: 0, step, 2*step, 3*step, ..., (size-1)*step. The function deliberately inserts these values in random order using a permutation generated by GetPermutation to exercise different tree insertion patterns and ensure comprehensive testing of red-black tree balancing operations.

The function serves dual purposes in testing:
1. **Initial Population**: Inserts all values in the sequence, expecting each insertion to be new (isNew = true)
2. **Collision Testing**: Re-inserts the first value to verify that collision detection and handling work correctly (expecting isNew = false on the duplicate insertion)

This approach ensures that both successful insertions and collision scenarios are tested within a single population operation, making it a comprehensive utility for red-black tree validation.

## Parameters / Member Variables
- `tree`: Pointer to the RBTree structure to populate (must be empty initially)
- `size`: Number of integers to insert into the tree (determines sequence length)
- `step`: The arithmetic progression step size (difference between consecutive values in the sequence)
