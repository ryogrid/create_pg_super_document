# binary_upgrade_set_next_toast_relfilenode

## Location
src/backend/utils/adt/pg_upgrade_support.c: 153 - 163

## Overview
Sets the next relfilenode number to be assigned to a TOAST relation during a binary upgrade process.

## Definition
```c
Datum binary_upgrade_set_next_toast_relfilenode(PG_FUNCTION_ARGS)
```

## Detailed Description
This function is part of PostgreSQL's binary upgrade infrastructure. It allows pg_upgrade to control the assignment of relfilenode numbers for TOAST relations by setting the global variable `binary_upgrade_next_toast_pg_class_relfilenumber` to a specific value. This ensures that after an upgrade, TOAST relations maintain their original relfilenode numbers, which is critical for preserving data integrity during the upgrade process.

The function can only be called when the server is running in binary upgrade mode (IsBinaryUpgrade is true), enforced by the CHECK_IS_BINARY_UPGRADE macro.

## Parameters / Member Variables
- `relfilenumber`: The RelFileNumber (OID) to be assigned to the next TOAST relation created during the binary upgrade
