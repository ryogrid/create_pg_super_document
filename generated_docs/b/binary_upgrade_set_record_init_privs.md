# binary_upgrade_set_record_init_privs

## Location

## Overview
Controls whether initial privileges should be recorded for objects created during a binary upgrade process.

## Definition
```c
Datum binary_upgrade_set_record_init_privs(PG_FUNCTION_ARGS)
```

## Detailed Description
This function is part of PostgreSQL's binary upgrade infrastructure that manages privilege recording behavior during database upgrades. It sets the global boolean variable `binary_upgrade_record_init_privs` to control whether the system should record initial privileges for database objects as they are created during the upgrade process.

When set to true, the system will record the initial default privileges for objects, which is important for maintaining proper security contexts and access controls across version upgrades. When false, initial privileges are not recorded, which may be appropriate for certain upgrade scenarios where privilege information is handled separately.

The function can only be executed when the server is running in binary upgrade mode, enforced by the CHECK_IS_BINARY_UPGRADE macro.

## Parameters / Member Variables
- `record_init_privs`: Boolean flag indicating whether to record initial privileges for objects created during binary upgrade (true = record, false = do not record)
