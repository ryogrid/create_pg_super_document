# binary_upgrade_create_empty_extension

## Overview
Creates an empty extension entry in pg_extension during a binary upgrade, without installing its constituent objects.

## Definition
```c
Datum binary_upgrade_create_empty_extension(PG_FUNCTION_ARGS)
```

## Detailed Description
This function is a specialized component of PostgreSQL's binary upgrade infrastructure that handles the creation of extension metadata during pg_upgrade operations. Unlike normal extension creation, this function creates only the catalog entry for an extension without actually installing any of its constituent objects (functions, types, etc.). This approach is necessary during binary upgrades because the extension's objects already exist in the database from the previous version and need to be associated with the extension without being recreated.

The function accepts seven parameters that define all aspects of the extension: name, schema, relocatability, version, configuration arrays, condition arrays, and dependencies. It validates required parameters and calls InsertExtensionTuple to create the pg_extension entry.

The function can only be executed during binary upgrade mode, verified by CHECK_IS_BINARY_UPGRADE macro.

## Parameters / Member Variables
- `extName`: Name of the extension (required, TEXT)
- `schemaName`: Schema where the extension will be installed (required, TEXT)
- `relocatable`: Whether the extension can be moved between schemas (required, BOOLEAN)
- `extVersion`: Version string of the extension (required, TEXT)
- `extConfig`: Configuration array for extension objects (optional, can be NULL)
- `extCondition`: Condition array for extension objects (optional, can be NULL)
- `requiredExtensions`: Array of extension names that this extension depends on (optional, TEXT[])
