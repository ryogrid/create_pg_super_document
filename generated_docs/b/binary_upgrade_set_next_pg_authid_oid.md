## Overview
Sets the next OID to be assigned to a role or user in pg_authid during a binary upgrade process.

## Definition
```c
Datum binary_upgrade_set_next_pg_authid_oid(PG_FUNCTION_ARGS)
```

## Detailed Description
This function is part of PostgreSQL's binary upgrade infrastructure that allows pg_upgrade to preserve role and user OIDs during database version upgrades. It sets the global variable `binary_upgrade_next_pg_authid_oid` to a specific OID value, ensuring that the next role or user created will use this predetermined OID instead of generating a new one. This is critical for maintaining authentication and authorization consistency, as role OIDs are used throughout the system for permissions, ownership, and security contexts.

The function can only be called when the server is running in binary upgrade mode, enforced by the CHECK_IS_BINARY_UPGRADE macro.

## Parameters / Member Variables
- `authoid`: The OID to be assigned to the next role or user entry in pg_authid during the binary upgrade
