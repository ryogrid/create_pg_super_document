# binary_upgrade_set_next_pg_enum_oid

## Location
src/backend/utils/adt/pg_upgrade_support.c: 164 - 174

## Overview
Sets the next OID to be assigned to an enum value in pg_enum during a binary upgrade process.

## Definition
```c
Datum binary_upgrade_set_next_pg_enum_oid(PG_FUNCTION_ARGS)
```

## Detailed Description
This function is part of PostgreSQL's binary upgrade infrastructure that enables pg_upgrade to preserve enum value OIDs during version upgrades. It sets the global variable `binary_upgrade_next_pg_enum_oid` to a specific OID value, ensuring that the next enum value created will use this predetermined OID rather than generating a new one. This is crucial for maintaining referential integrity and avoiding OID conflicts when upgrading databases that contain enum types.

The function can only be executed when the server is running in binary upgrade mode, which is verified by the CHECK_IS_BINARY_UPGRADE macro.

## Parameters / Member Variables
- `enumoid`: The OID to be assigned to the next enum value entry in pg_enum during the binary upgrade
