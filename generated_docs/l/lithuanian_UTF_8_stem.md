## Overview
The lithuanian_UTF_8_stem function is the main entry point for Lithuanian word stemming, implementing the complete stemming algorithm by orchestrating multiple processing steps and morphological transformations.

## Definition
extern int lithuanian_UTF_8_stem(struct SN_env * z)

## Detailed Description
This function implements the complete Lithuanian stemming algorithm using the Snowball stemming framework. It processes Lithuanian words through multiple sequential steps: 1) Sets up the R1 region by finding the first vowel-consonant-vowel sequence or ensuring minimum word length, 2) Applies conflict resolution for morphological ambiguities, 3) Performs primary suffix removal (step1), 4) Fixes 'ch' and 'dz' phonetic patterns, 5) Applies secondary suffix removal (step2), 6) Repeats phonetic fixes for 'ch'/'dz' and 'gd' patterns, and 7) Returns the cursor to the beginning for final result. The function uses backward processing (from end to beginning) for most operations and maintains state through cursor positions and region boundaries.

## Notes and Other Information
This is the main Lithuanian stemming algorithm generated by Snowball 2.2.0. The function operates on UTF-8 encoded Lithuanian text and handles Unicode characters specific to Lithuanian (such as ą, č, ę, ė, į, š, ų, ū, ž). The algorithm follows the standard Snowball pattern of R1 region identification followed by multiple passes of suffix removal and phonetic corrections. The function always returns 1 on successful completion, or negative values on UTF-8 processing errors. All morphological transformations are applied in a specific order to ensure correct Lithuanian word normalization.
