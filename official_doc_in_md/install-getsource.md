## 17.2. Getting the Source #

The PostgreSQL source code for released versions can be obtained from the download section of our website: <https://www.postgresql.org/ftp/source/>. Download the `postgresql-_`version`_.tar.gz` or `postgresql-_`version`_.tar.bz2` file you're interested in, then unpack it: 
    
    
    **tar xf postgresql-_version_.tar.bz2**
    

This will create a directory `postgresql-_`version`_` under the current directory with the PostgreSQL sources. Change into that directory for the rest of the installation procedure. 

Alternatively, you can use the Git version control system; see [Section I.1](git.md "I.1. Getting the Source via Git") for more information.
