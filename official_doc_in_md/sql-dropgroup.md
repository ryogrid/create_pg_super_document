## DROP GROUP

DROP GROUP — remove a database role

## Synopsis
    
    
    DROP GROUP [ IF EXISTS ] _name_ [, ...]
    

## Description

`DROP GROUP` is now an alias for [`DROP ROLE`](sql-droprole.md "DROP ROLE"). 

## Compatibility

There is no `DROP GROUP` statement in the SQL standard.
