=== NOTES ===

Node type count: 43 distinct plan node types

MultiExecProcNode nodes (return non-tuple data):
  - T_Hash -> MultiExecHash (returns hashtable)
  - T_BitmapIndexScan -> MultiExecBitmapIndexScan (returns TIDBitmap)
  - T_BitmapAnd -> MultiExecBitmapAnd (returns TIDBitmap)
  - T_BitmapOr -> MultiExecBitmapOr (returns TIDBitmap)

Nodes with empty ExecEnd (cleanup handled by memory context destruction):
  - T_ValuesScan (T_ValuesScanState)
  - T_NamedTuplestoreScan (T_NamedTuplestoreScanState)
  - T_WorkTableScan (T_WorkTableScanState)

Aggregation strategies for T_Agg:
  - AGG_PLAIN: no grouping
  - AGG_SORTED: pre-sorted input
  - AGG_HASHED: hash-based grouping
  - AGG_MIXED: combination for GROUPING SETS

ModifyTable operation types:
  - CMD_INSERT
  - CMD_UPDATE
  - CMD_DELETE
  - CMD_MERGE

All scan nodes delegate to ExecScan() with node-specific access/recheck methods:
  SeqScan, SampleScan, IndexScan, IndexOnlyScan, BitmapHeapScan, TidScan,
  TidRangeScan, SubqueryScan, FunctionScan, TableFuncScan, ValuesScan,
  CteScan, NamedTuplestoreScan, WorkTableScan, ForeignScan, CustomScan
