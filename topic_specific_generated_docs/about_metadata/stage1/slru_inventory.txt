1. CLOG  (transaction commit/abort log)
================================================================================
SlruCtl              : XactCtl
Source file          : src/backend/access/transam/clog.c (SimpleLruInit at line 811)
On-disk directory    : pg_xact
Page-number formula  : TransactionIdToPage(xid) = xid / CLOG_XACTS_PER_PAGE
                       CLOG_XACTS_PER_PAGE = BLCKSZ * CLOG_XACTS_PER_BYTE = BLCKSZ * 4 = 32768
Per-page data        : 2 bits per XID; 4 XIDs per byte; 32768 XIDs per 8KB page
WAL-logged           : YES — uses CLOG_LSNS_PER_PAGE (CLOG_XACTS_PER_PAGE / 32 = 1024) async-LSN
                       slots per page; SimpleLruInit's nlsns argument is CLOG_LSNS_PER_PAGE,
                       so that XLogFlush() is called before a CLOG page is written when
                       async-commit transactions affected it.
Checkpoint hook      : CheckPointCLOG  (calls SimpleLruWriteAll)
Truncate policy      : TruncateCLOG, called from vac_truncate_clog after vacuum advances
                       the cluster-wide oldestXid (datfrozenxid). Cutoff is the page
                       containing oldestXid; emits XLOG_CLOG_TRUNCATE first.
Redo callback        : clog_redo (clog.c:1107)
                       XLOG_CLOG_ZEROPAGE   = 0x00 (info byte; clog.h:55)
                       XLOG_CLOG_TRUNCATE   = 0x10 (info byte; clog.h:56)

================================================================================
SlruCtl              : SubTransCtl
Source file          : src/backend/access/transam/subtrans.c (SimpleLruInit at line 244)
On-disk directory    : pg_subtrans
Page-number formula  : TransactionIdToPage(xid) = xid / SUBTRANS_XACTS_PER_PAGE

Per-page data        : 4 bytes per XID (parent TransactionId); 2048 XIDs per 8KB page

Truncate policy      : TruncateSUBTRANS, called as part of vac_truncate_clog using
                       oldestActiveXact. No WAL emitted — recovery rebuilds the file.
Redo callback        : (none; subtrans has no rmgr)
